# Subagent step traces are persisted and surfaced to the user, but never returned to the caller

`run_subagent` returns only a distilled summary to the calling Agent, by design — that isolation is what makes Subagents useful (bounded context, no transcript bloat in the parent conversation). Today `runSubagent.ts` actually discards the underlying `result.steps` entirely once the summary is computed, and the only trace of execution visible anywhere is a single global, overwritten-per-step label (`agentMeta.step`) with no per-subagent identity and no history. This makes a running or completed Subagent a black box to the user: there's no way to see what it actually did, which matters for trust and debugging, especially for multi-step Explorers hitting external Integrations.

We're keeping the step trace instead of discarding it: capturing each step (tool name, label, input, output, duration) into a per-`toolCallId` map in `chatStore` while the Subagent runs (so parallel Subagents each get their own live trace), then flushing that array into the `run_subagent` tool-call's output when it finishes, so it persists in `neira-sessions.json` alongside the rest of the message and can be reopened after a reload. The existing `Tool` card's `Collapsible` pattern is extended with a nested per-step expand, rather than introducing a separate panel or store, since `AiChat.tsx` already renders and subscribes to that path.

The trade-off is explicit: this is user-facing visibility only. The step trace is never assembled back into the calling Agent's message history — the caller-side isolation contract from `run_subagent`'s original design is unchanged. We accepted a modest persistence cost (step traces bloating `neira-sessions.json`) by truncating large per-step outputs, rather than dropping older steps or leaving the trace ephemeral, because losing it on reload would defeat the debugging/audit purpose. If session file size becomes a real problem, the next lever is a step-count or age-based eviction on the persisted trace, not on the live one.
